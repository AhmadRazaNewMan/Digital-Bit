# Covering Indexes and Index-Only Scans
## What
Covering indexes are a type of index in database management systems (DBMS) that include all the columns needed to answer a query. This means that the index contains not only the columns used for filtering and joining, but also the columns needed for the select clause. Index-only scans are a technique used by the database to retrieve data from the index without accessing the underlying table.

## Why
Covering indexes and index-only scans are useful because they can improve query performance by reducing the number of disk I/O operations. By including all the necessary columns in the index, the database can retrieve all the required data from the index, without needing to access the underlying table. This can be especially beneficial for queries that only need to retrieve a subset of columns from a large table.

## How
To create a covering index, the database administrator needs to include all the columns needed to answer a query in the index. This can be done by specifying the included columns in the CREATE INDEX statement. For example, if we have a query that retrieves the customer name and order total for a given customer ID, we can create a covering index on the customer ID column that includes the customer name and order total columns.

## One exercise or command
Create a covering index on a table to improve query performance:
```sql
CREATE INDEX idx_customer_id ON customers (customer_id) INCLUDE (customer_name, order_total);
```
This will create a covering index on the customer ID column that includes the customer name and order total columns, allowing the database to retrieve all the required data from the index without accessing the underlying table.
