# Covering Indexes and Index-Only Scans
## What
Covering indexes are a type of database index that includes all the columns needed to answer a query, allowing the database to retrieve all required data from the index itself without accessing the underlying table. Index-only scans are a technique used by databases to retrieve data only from the index, reducing the number of disk I/O operations and improving query performance.

## Why
Covering indexes and index-only scans are useful for several reasons:
* They reduce the number of disk I/O operations, resulting in faster query execution times
* They minimize the amount of data that needs to be retrieved from disk, reducing memory usage and improving system performance
* They can be particularly effective for queries that only require a subset of columns from a table

## How
To create a covering index, you need to include all the columns required by a query in the index. This can be done by creating a composite index that includes all the necessary columns. The database will then use the index to retrieve all required data, eliminating the need to access the underlying table.

## One exercise or command
Create a covering index on a table to improve query performance: 
```sql
CREATE INDEX idx_name ON table_name (column1, column2, column3);
```
This will create a composite index that includes all the columns required by a query, allowing the database to use an index-only scan to retrieve the required data.
